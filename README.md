# tarot-images

tarot-images use to create a html platform for tarot to do the magic. Only for personal use.

## 星空塔羅 Star Tarot

純前端的互動塔羅網頁，打開 `index.html` 即可使用（建議用本機伺服器，例如 `python3 -m http.server`，或放上 GitHub Pages）。

- **起始頁**：中央浮動的牌卡周圍，情境沿著星座軌道環繞，點選或滑動把情境轉到正前方，背景光暈跟著換色。今天還沒抽每日一牌時會先停在每日一牌，抽過後軌道上就只剩五個情境。下方是問題框和「開始洗牌」，右側的圓鈕會展開成可旋轉的牌陣輪盤，轉到正上方的就是選中的牌陣
- **隨手一抽**：不用情境和牌陣，從卡夾裡拉出一張牌，翻開後直接給出結論（去做吧／時機未到／再想想／先不要）、關鍵字與一句建議
- **情境專屬牌陣**：每個情境的輪盤只列出適合的三種牌陣，包含對方的心、職場人際、考試運勢、情緒療癒等專屬牌陣
- **3D 牌環抽牌**：洗好的牌圍成一圈立體牌環，左右滑動旋轉，點一張牌就沿著弧線飛到牌位（先蓋著）
- **翻牌儀式**：牌到齊後一張張點開（或全部翻開），翻牌時有蓄力、魔法陣、浮起翻面、依花色的光點，大牌還有全畫面的光
- **牌面活起來**：翻開的牌會依類型動起來：大牌光束、聖杯氣泡、權杖火星、寶劍刀光、錢幣金光
- **星座連線**：抽完後牌與牌之間連起發光的線，點中間的星星看兩張牌的元素關係
- **全息閃卡**：滑鼠移到牌上會有彩虹反光與傾斜效果
- **詳細解讀**：每張牌都有正逆位牌義、感情、事業／學業與建議，並依牌位、數字與花色組成解說
- **完整解讀**：最上方先給一段總結（整體走向、關鍵牌、一句建議），再接整體能量分析（元素、花色、數字、正逆位、宮廷牌）、牌陣的故事、逐張解讀、分面向解讀與建議
- **牌卡畫廊**：78 張牌排成可拖曳旋轉的 3D 圓柱
- **星空水族館**：星空背景裡，偶爾會有由星星連成的海洋生物游過：鯊鯊、鯨鯊、魔鬼魟、海龜、水母、海馬
- **問題靈感**：問題框右側的「靈感」按鈕，會依分類輪流填入建議問法
- **問題分類**：抽牌前可選綜合／感情／事業／學業／自我成長，解讀會加上該面向的專屬段落
- **占卜紀錄**：每次占卜自動存在這台裝置的瀏覽器裡，可以回頭查看、寫下「後來怎麼樣了」的回顧筆記
- **每日一牌日曆**：每日一牌一天只能抽一張，抽過的牌排成月曆，顯示抽牌天數、連續天數與本月的元素、花色、逆位統計（在 📖 裡切換）
- **存成圖片**：把牌陣與重點解讀合成一張 1080×1920 的直式圖片，可直接分享或下載

## 檔案結構

| 檔案 | 內容 |
|---|---|
| `index.html`、`style.css` | 頁面與樣式 |
| `meanings.js` | 78 張牌的牌義（正逆位、感情、事業／學業、自我成長、逆位的各面向、建議） |
| `cards.js` | 牌的資料、牌陣、每個情境適用的牌陣 |
| `reading.js` | 把抽到的牌組成解讀文字（總結、故事、情境解讀、隨手一抽的結論） |
| `live.js` | 牌面活起來的動態 |
| `js/core.js` | 共用工具、狀態、星空背景、粒子特效、音效 |
| `js/table.js` | 牌桌版面、牌位與牌的建立 |
| `js/home.js` | 起始頁：星座軌道、每日一牌與隨手一抽的入口 |
| `js/quick.js` | 隨手一抽 |
| `js/wheel.js` | 牌陣輪盤 |
| `js/draw.js` | 洗牌、3D 牌環、抽牌、翻牌、回到起始頁 |
| `js/views.js` | 單張牌詳情、完整解讀、占卜紀錄、星座連線 |
| `js/extras.js` | 每日一牌日曆、存成圖片、牌卡畫廊 |
| `js/main.js` | 按鈕事件與初始化 |
| `cards/` | 網頁用的牌卡圖片（由 `tarot-v3/` 的原始 PNG 縮小而來） |
| `tests/run.js` | 自動測試 |

`js/` 裡的檔案依序載入（順序寫在 `index.html`），彼此共用變數，所以不要隨意調換順序。修改 JS 或 CSS 後，記得更新 `index.html` 裡的 `?v=` 版本號，手機才會抓到新檔案。

## 自動測試

在模擬的 iPhone 與電腦瀏覽器裡跑完整流程，約 6～7 分鐘：

```bash
npm i -D playwright && npx playwright install chromium   # 第一次才需要
node tests/run.js                # 全部
node tests/run.js quick zoom     # 只跑指定項目
```

| 項目 | 檢查什麼 |
|---|---|
| `flow` | 各情境的牌陣都能從頭抽到完整解讀（手機與電腦） |
| `daily` | 每日一牌抽完後顯示「今日已抽」，再點是回顧 |
| `quick` | 隨手一抽能抽出結論，並存進紀錄 |
| `scenes` | 每個情境只列出自己的牌陣，編號從 I 開始 |
| `stress` | 快速操作後不會出錯，起始頁繪圖量不會大到讓 iPhone 當掉 |
| `zoom` | 畫面被放大時，牌的位置不會跑掉 |
