# tarot-images

tarot-images use to create a html platform for tarot to do the magic. Only for personal use.

## 星空塔羅 Star Tarot

純前端的互動塔羅網頁，打開 `index.html` 即可使用（建議用本機伺服器，例如 `python3 -m http.server`，或放上 GitHub Pages）。

- **洗牌儀式**：點擊牌堆或按「洗牌」，手機可以搖一搖
- **扇形抽牌**：78 張牌展開成弧形，憑直覺點選，牌會飛到牌位並 3D 翻面
- **三種牌陣**：每日一牌、一大三小（先從 22 張大阿爾克那抽 1 張主題牌，再從 56 張小阿爾克那抽過去／現在／未來）、凱爾特十字
- **星座連線**：抽完後牌與牌之間連起發光的線，點中間的星星看兩張牌的元素關係
- **全息閃卡**：滑鼠移到牌上會有彩虹反光與傾斜效果
- **詳細解讀**：每張牌都有正逆位牌義、感情、事業／學業與建議，並依牌位、數字與花色組成解說
- **完整解讀**：整體能量分析（元素、花色、數字、正逆位、宮廷牌）、牌陣的故事、逐張解讀、分面向解讀與建議
- **牌卡畫廊**：78 張牌排成可拖曳旋轉的 3D 圓柱
- **問題分類**：抽牌前可選綜合／感情／事業／學業／自我成長，解讀會加上該面向的專屬段落
- **占卜紀錄**：每次占卜自動存在這台裝置的瀏覽器裡，可以回頭查看、寫下「後來怎麼樣了」的回顧筆記
- **存成圖片**：把牌陣與重點解讀合成一張 1080×1920 的直式圖片，可直接分享或下載

檔案：`index.html`、`style.css`、`app.js`（互動與動畫）、`cards.js`（牌與牌陣資料）、`meanings.js`（詳細牌義）、`reading.js`（解讀文字組合），`thumbs/` 是給網頁用的縮圖。
